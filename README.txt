寵物急救考試 PWA V2｜課程筆試、操作考核

檔案必須整個一起上傳：index.html、app.js、data.js、sources.js、style.css、sw.js、manifest.webmanifest、icon.svg、assets/。

V2 內容：7 章講義、87 道依原講義編寫的非官方模擬題、30 題隨機模擬考、193 頁可搜尋的原講義圖像、實作檢查表、錯題紀錄備份/匯入。

新增「原講義查閱」可搜尋、依章節篩選並放大原始頁面。來源圖像不是另外搜尋的示意圖，均摘自使用者提供的三份講義。

部署：將資料夾內全部檔案上傳到 GitHub Pages 或 Netlify Drop。不要只上傳 index.html 或未解壓 ZIP。
紀錄：沿用 v1 localStorage 儲存鍵；同一網址同一瀏覽器原紀錄可保留，但不同網址或瀏覽器不能自動同步，建議升級前先匯出學習紀錄。
注意：原始講義部分數值相互矛盾（如第一份 P.4 與 P.8 呼吸頻率），請課堂向老師確認。傷口止血帶、催吐、窒息處置等急救操作不可自行當醫療處置指南。

交付前靜態檢查：87 題答案均存在選項內，選項無重複，章節 ID 正確；193 張來源頁面圖及所有章節圖片均存在；題目講義頁碼均能對到來源頁面；JS 語法通過。注意：執行環境的瀏覽器禁止開啟本地及 localhost 頁面，未能完成真實瀏覽器端逐項測試，請勿視為已驗收所有手機功能。
